# Nombre por escucharse (Propongo "DejelaSonar.com" o "LetItSound.com")
### Version de python : 3.13
Reproductor musical local cuyo principal proposito es la descarga directa al dispositivo de musica de distintas fuentes usando la api yt-dlp (https://github.com/yt-dlp/yt-dlp).
Entre sus principales funciones se encuentra: 
- control sobre la manera en que se guardan los archivos en el almacenamiento del dispositivo
- Guardado local de las descargas, si borras la app podras conservar la musica en tu dispositivo!
- Estetica de playlist personalizable
- IA integrada que:
    - ayudara en la busqueda de canciones por similitudes.
    - Dara informacion respectiva al artista o a la cancion.
- Control de reproduccion, como repetir en bucle o temporizador de apagado
- funciones que facilitan el compartir musica con amigos

Entre sus funciones secundarias se encuentra:
- Bloc de notas integrado para desbordar sentimientos y recordar
- "Vibes" personalizadas a gusto del usuario
- Dinamicas interactivas ("como volver al pasado")
- Mix de canciones con alisamiento de las transiciones entre cancion y cancion
- GUI personalizable
- Letras sincronizadas con las canciones
- Ecualizador integrado.

El proyecto toma inspiracion de otros proyectos de codigo abierto como Strawberry (https://github.com/strawberry-graphql/strawberry?tab=readme-ov-file) y el Y2mate (https://github.com/Simatwa/y2mate-api )

## Version Pre-Alpha
Solo contara con una interfaz de linea de comandos (CLI), ademas solo sera usable en computadores personales y no en celulares moviles. Tendra funciones reducidas y se centrara en conseguir el objetivo principal, bajar musica de la web, almacenarla de forma organizada y personalizada en el almacenamiento local del dispositivo y permitir su reproduccion desde la app.

## Version Alpha
