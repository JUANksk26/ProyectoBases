Una aclaración: la página oficial de PostgreSQL (postgresql.org/download/linux) explica la instalación con dnf/apt, pero Bazzite es un sistema inmutable y ahí no conviene instalar así. Lo más limpio es correr PostgreSQL oficial en un contenedor con Podman, que ya viene instalado en Bazzite.

PARTE 1: Instalar y arrancar PostgreSQL

1. Abre una terminal y crea el servidor (cambia TU_CONTRASEÑA por la que quieras):

podman run -d --name letit-db -e POSTGRES_PASSWORD=TU_CONTRASEÑA -e POSTGRES_DB=letit -p 5432:5432 -v letit-data:/var/lib/postgresql/data docker.io/library/postgres:17

- La primera vez descarga la imagen, tarda un poco.
- El volumen letit-data hace que los datos no se pierdan al apagar el contenedor.
- Crea de una vez la base de datos llamada letit.

2. Comprueba que está corriendo:

podman ps

3. Crea las tablas con el archivo Tablas.sql (estando en la carpeta donde lo tengas):

podman exec -i letit-db psql -U postgres -d letit < Tablas.sql

4. Cuando reinicies el PC, el contenedor queda apagado. Para encenderlo otra vez:

podman start letit-db

(Alternativa si prefieres instalarlo como en la página oficial: crea un contenedor con distrobox usando Ubuntu o Fedora, y dentro sigues las instrucciones de postgresql.org/download/linux. Pero el método de Podman es más simple.)

PARTE 2: Conectarlo en VS Code con la extensión oficial de Microsoft

1. Abre VS Code y entra a Extensiones (Ctrl+Shift+X).
2. Busca PostgreSQL y elige la que dice Microsoft como publicador (ID: ms-ossdata.vscode-pgsql). Dale Install.
3. Aparece un icono de elefante en la barra lateral. Ábrelo y pulsa Add Connection.
4. Llena los datos:
- Host: localhost
- Port: 5432
- User: postgres
- Password: la que pusiste en el paso 1
- Database: letit
5. Guarda y conéctate. Deberías ver el árbol con las tablas (usuario, artista, album, cancion...). Desde ahí puedes abrir un editor SQL y hacer consultas, por ejemplo: SELECT * FROM cancion;

PARTE 3: Que el código Python se conecte

En db.py hay un diccionario DB_CONFIG. Ahí pon tu contraseña y deja dbname como letit, host localhost y puerto 5432. Además instala el conector con:

pip install psycopg2-binary mutagen
